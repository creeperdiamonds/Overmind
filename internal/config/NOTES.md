# config

Reads the settings file and holds the defaults.

`Seed` is a pointer so that 0, a real seed, is told apart from "not set" (a random seed is chosen and kept in the world folder, see `internal/app`). `RandomTickSpeed` 0 is Dragonfly's normal 3 blocks per sub chunk per tick; tests raise it. `ChunkWorkers` 0 means min(4, processors). `Profile` picks the world's placement rules, `bedrock` (default) or `overjava`; an unknown name is a start error. `BedrockDataDir` is a local Bedrock install whose vanilla feature data the Bedrock profile reads at startup. Only a Bedrock Dedicated Server folder gives an exact world: its `definitions` folder holds rules and features no pack has (the clay disk, the roofed forest's trees, the legacy table's trees, the second cave carver). A game's `behavior_packs` folder is read too, and the log warns that the world will not be exact and what is missing. Empty or unreadable, the profile uses its built-in, approximate features and the log says so in one line. `TickDistance` 0 is Bedrock's default 4; `internal/app` holds it at least two under `ViewDistance` so a tick never has to generate a chunk.
